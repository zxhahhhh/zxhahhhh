# 羽函

让你的鱼有情绪，有体感。

## 身体时钟

[universal-body-clock](https://github.com/zxhahhhh/universal-body-clock) —— DeepSeek Harness 的插件。

十格、八维、欲望、情绪、距离。碰过哪儿、多久没说话、人走没走，都记着。它自己往下走，也会读你正文里写的动作。下次开口，它知道。

## 为什么做

大多角色扮演停在一句设定上。设定不会变，鱼也不该是。

这个插件把身子写成一本会变的账：同一个动作，隔半天再碰，落下的数不一样。
